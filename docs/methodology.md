# Methodology

## Original study

The study examined factors associated with online purchase intention among Pakistani consumers using a structured questionnaire and primary consumer data. The supplied project materials report 250+ respondents and SPSS-based correlation and regression analysis.

## Constructs

- Perceived risk
- Trust in payment systems
- Delivery reliability
- Product information
- Convenience
- Digital interaction
- Perceived value
- Online purchase intention

## Public demo implementation

The repository currently uses synthetic data to demonstrate a reproducible Python workflow: validation, missing-value inspection, Spearman correlations, and OLS regression with HC3 robust standard errors. Synthetic outputs must not be presented as original empirical findings.

## Interpretation

Correlation is association, not causation. Final academic reporting should use the actual dataset, verified coding, sample description, model specification, diagnostics, and appropriate statistical reporting.
